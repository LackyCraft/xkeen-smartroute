# Вкладка «Домены» / Domains

Собственные списки доменов (не путать со списками geosite Xray) — источник
доменов при создании профиля, наравне с geosite-категориями. Отдельная
вкладка только в панели SmartRoute; в LuCI это встроено прямо во вкладку
«Профили» (см. [profiles.md](profiles.md), раздел «Управление списками
доменов») — та же самая логика и тот же backend, просто другое место в
интерфейсе.

![Домены — панель SmartRoute](../screenshots/SmartRouteUI/DomainsPage.png)

## Добавить свой домен(ы)

Имя списка + домены через запятую — создаёт **новый** список и сразу делает
его доступным в выборе источника доменов на вкладке «Профили». Не добавляет
домены в уже существующий список — для этого нужна карточка списка ниже.
Имя, которое уже занято существующим списком, отклоняется с понятной
причиной (добавьте домен в существующий список вместо создания нового).

Домены санитизируются на лету: вставили `https://2ip.ru/some/path` —
сохранится `2ip.ru`, с уведомлением, что именно изменилось. Работает так,
потому что `sanitize_domain()` на backend делает то же самое — что
показывает интерфейс, то и реально сохранится.

## Управление списками доменов

Сворачиваемые карточки, одна на список:

- Просмотр всех доменов списка.
- Добавление отдельного домена (санитизируется так же, как при создании).
- Удаление отдельного домена.
- Удаление списка целиком, с подтверждением.

Список, используемый как источник доменов в каком-то профиле, можно удалить
— профиль при этом не удаляется, но перестаёт матчить домены (тот же эффект,
как если бы список опустел).
