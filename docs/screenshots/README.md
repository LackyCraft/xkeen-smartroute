# Screenshots / Скриншоты

Реальные скриншоты обоих интерфейсов — LuCI-модуля (`OpenWRTUI/`) и отдельной
панели SmartRoute на порту 1001 (`SmartRouteUI/`). Адреса серверов на части
скриншотов замазаны/зачёрнуты вручную — это осознанная приватность, не
дефект.

Real screenshots of both interfaces — the LuCI module (`OpenWRTUI/`) and the
standalone SmartRoute panel on port 1001 (`SmartRouteUI/`). Server addresses
are manually redacted/blacked out on some screenshots on purpose, not a
rendering defect.

Нет отдельного скриншота «Домены» — в LuCI управление собственными списками
доменов встроено в вкладку «Профили» (`ProfilesPage2.png`), а не вынесено в
отдельную вкладку, как в панели SmartRoute.

No separate "Domains" screenshot — in LuCI, custom domain-list management
lives inside the "Profiles" tab (`ProfilesPage2.png`) rather than its own tab,
unlike the SmartRoute panel.
